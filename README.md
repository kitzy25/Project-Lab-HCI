Asphalt 9: Rejends

Asphalt 9: Rejends is a Human Computer Interaction lab final project designed to give information about the website and subscription format.
This Asphalt 9: Rejends is designed at the Front End Development stage using HTML, CSS, JavaScript. The design itself giving some gaming
vibes with red and black colors. This design is equipped with several features such as homepage, product page, news page, esport page and
subscription page.
